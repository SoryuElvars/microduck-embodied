# MicroDuck model_5999：左右腿 Action 镜像诊断

## 结论

`model_5999` 的左右不对称已经存在于导出的 ONNX 策略（包括其内置 Observation
Normalizer）中，不能只归因于 MuJoCo 或 BAM M6 执行器动力学。负向旋转失败的
直接表现是大部分腿部 Action 相对正向旋转整体减弱，其中膝关节和髋滚转最严重。

横移问题与旋转问题的形态不同：正负横移的总体 Action RMS 没有整体塌缩，但
左右膝和髋滚转的动作波形无法形成合理镜像，闭环轨迹因此快速分化。

## 两层对比方法

### 1. ONNX 镜像等变检查

使用官方 `microduck_rl/src/mjlab_microduck/tasks/symmetry.py` 的镜像规则：

```text
期望：π(Mirror(observation)) ≈ Mirror(π(observation))
误差：π(Mirror(observation)) - Mirror(π(observation))
```

- 左右腿关节 `0–4 ↔ 9–13`；腿部 Action 交换后取反。
- `vy`、`wz` 指令取反，`vx` 保持不变。
- 从全部 160 个 Episode 每 5 个控制步采样一次，共检查 16,000 个 Observation。
- 为验证输入链路，用未镜像的 Observation 重新推理并对比 CSV Action，重放
  RMSE 为精确的 `0.000e+00`。

结果：

| 指标 | 数值 |
|---|---:|
| ONNX 镜像等变整体 RMSE | `0.064674` |
| 被镜像 Action 的整体 RMS | `0.183388` |
| 归一化镜像误差 | `35.3%` |

误差最大的输出关节：

| 关节 | 镜像 RMSE | 相对该关节 Action RMS |
|---|---:|---:|
| `head_yaw` | `0.09876` | `72.7%` |
| `left_hip_yaw` | `0.08018` | `85.6%` |
| `left_ankle` | `0.07937` | `67.3%` |
| `left_hip_roll` | `0.06590` | `40.2%` |
| `right_hip_yaw` | `0.06485` | `100.2%` |
| `left_knee` | `0.06407` | `18.1%` |

这项检查不经过第二条闭环轨迹，因此直接证明策略映射本身没有满足官方镜像关系。

## 闭环正负指令对比

正负指令使用完全相同的种子 `42–61`。每一对 Episode 在相同控制步比较完整
50 Hz Action，共 10,000 对样本。

| 指令对 | 闭环镜像 RMSE | 最大误差关节 | 第二大误差关节 |
|---|---:|---:|---:|
| `wz=+0.5 ↔ -0.5` | `0.174286` | 左膝 `0.3959` | 右膝 `0.3362` |
| `vy=+0.2 ↔ -0.2` | `0.258073` | 左膝 `0.5985` | 右膝 `0.4792` |

闭环误差包含策略不对称被动力学逐步放大的影响，因此数值大于 ONNX 单步镜像误差
是合理的；不能把它单独解释成某个执行器误差。

## 负向旋转为何几乎不动

将负向旋转 Action 镜像回正向坐标后，与正向旋转比较每个关节的 Action RMS：

| 正向坐标中的关节 | `wz=+0.5` RMS | 镜像后的 `wz=-0.5` RMS | 负/正比值 |
|---|---:|---:|---:|
| 左膝 | `0.3366` | `0.0342` | `10.2%` |
| 右髋滚转 | `0.1645` | `0.0331` | `20.1%` |
| 左踝 | `0.0491` | `0.0141` | `28.8%` |
| 颈俯仰 | `0.0678` | `0.0250` | `36.9%` |
| 右髋偏航 | `0.1475` | `0.0595` | `40.3%` |
| 左髋俯仰 | `0.1473` | `0.0596` | `40.5%` |
| 左髋偏航 | `0.0611` | `0.0253` | `41.4%` |
| 左髋滚转 | `0.1481` | `0.0698` | `47.1%` |

因此 `wz=-0.5` 的失败不是“生成了正确镜像动作但物理没有响应”，而是策略根本没有
产生与正向旋转等价的腿部动作强度。

## 横移与直行的关节线索

- 横移闭环镜像误差集中在左右膝（`0.5985/0.4792`）和左右髋滚转
  （`0.2969/0.2462`）。
- 正负横移的多数关节 RMS 比值处于约 `0.68–1.44`，没有负向旋转那种全局动作
  熄火；更像腿间协调、相位或动作波形不匹配。
- `vx=+0.3` 直行时，左右踝 Action RMS 相差 `20.2%`、左右髋偏航相差
  `19.9%`。
- `vx=-0.3` 后退时，左右髋偏航 Action RMS 相差 `29.0%`。

这些直行幅度差异与此前前进/后退的大弧线一致，但目前还没有定义正式的关节级
通过阈值，因此只作为排序和后续对比依据。

## 训练配置证据

本 Checkpoint 保存的 `params/agent.yaml` 中为：

```text
symmetry_cfg: null
```

当前官方 `microduck_velocity_env_cfg.py` 也为 `ENABLE_SYMMETRY = False`。这说明
本次训练没有启用镜像损失，但它本身还不能证明“启用镜像损失一定能修好”；需要
先用旧 Checkpoint 判断不对称何时出现，再进行单变量训练实验。
